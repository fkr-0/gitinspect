Architecture

Rendering and repository authority stay separate.

React, Three.js and the generic graph-elements package own the visual world, interaction, topology projection, labels, camera and large-history LOD. Native Rust owns repository access, parsing, watching, diff extraction and the guarded mutation model.

The browser experiment preserves this line instead of pretending a desktop filesystem backend is available inside WebAssembly.

The experimental entry must successfully initialize a versioned Rust/WebAssembly module before the GitInspect UI appears. The module publishes a deterministic runtime fingerprint and an explicit fail-closed capability record. If WASM fails to load, the page reports that failure instead of silently calling the ordinary JavaScript demo a WebAssembly build.

Safety model

Browser availability does not widen mutation authority.

Inspection is read-only by default. Mutation workflows remain preview-first and original-repository apply remains outside the browser experiment.

The WASM capability contract explicitly reports mutationAuthority: false and nativeGit: false.
