## Objective and data contract

Implement a standalone Rust library that can open real Git repositories and serialize a snapshot matching the semantics of `GitRepositorySnapshot` in `packages/contracts/src/index.ts`.

Required first slice:

1. Discover/open worktree root, `.git` dir, linked-worktree `gitdir:` indirection, and bare repository paths using gix-aware discovery where possible.
2. Return canonical repository path/git dir, HEAD, stable snapshot revision fingerprint, commit list, refs, remotes, hooks, and truncation flag.
3. Commit records: oid, tree oid, parent oids, author identity/time, commit time, message. Signature status may be `unknown`/`unsigned` if robust verification is deferred, but the limitation must be explicit.
4. Enumerate local branches, remote branches, tags, stash ref/entries, other refs. Resolve symbolic target/upstream where available. Ahead/behind may be optional in first slice but add a clear seam.
5. Remotes: fetch/push URLs without network access.
6. Diff/stat seam: implement changed-file stats for at least normal text commits if gix APIs are tractable; otherwise provide a lazy API boundary with focused tests and state the blocker. Binary detection must never read unbounded blob data.
7. Repository watcher abstraction with debounced/coalesced change reasons. A focused test may use a fake watcher/event source; do not rely on timing-sensitive global filesystem state.
8. Read-only only in Phase 3. Do not implement destructive mutation apply.
